# aktbKetabAhmed-Mariam

دعوة عقد قران وخطوبة أحمد ومريم — تطبيق ويب تفاعلي ومخصص مبني بأحدث معايير React + TypeScript + Vite + Tailwind CSS.

## المميزات
- 💌 **ظرف تفاعلي ثلاثي الأبعاد (3D Interactive Envelope)** مع ختم شمعي كلاسيكي وتأثير خروج الكارت.
- 🌹 **خلفية بتلات الورد المتساقط التفاعلية (Realistic 3D Falling Roses & Petals)** مع استجابة لحركة المؤشر واللمس.
- 🎵 **محرك موسيقي توليدي (Web Audio Synthesizer)** يعزف ألحان شرقية رومانسية دافئة.
- 🎟️ **بطاقة حك الموعد (HTML5 Canvas Scratch-Off)** لكشف تاريخ الحفل مع تأثير الكونفيتي.
- 📸 **ألبوم صور البولارويد (3D Polaroid Stack)** مع خط زمني لحكاية العروسين.
- ⏳ **عد تنازلي مباشر (Live Countdown)** وتفاصيل القاعة مع كود QR مخصص وحفظ الموعد في التقويم (.ICS).
- ✍️ **دفتر المباركات وتأكيد الحضور (Wall of Wishes & RSVP)**.
- 📷 **مشاركة لقطات الحفل (Shared Photo Drop)** من قِبل الضيوف.
- ⚙️ **لوحة تخصيص متكاملة (Host Studio)** تتيح للعروسين تعديل الأسماء، التواريخ، الثيمات، وتوليد روابط خاصة للضيوف (VIP Links).

## التشغيل والتطوير
```bash
# تثبيت الحزم
bun install

# تشغيل خادم التطوير
bun run dev

# بناء حزمة الإنتاج
bun run build
```
